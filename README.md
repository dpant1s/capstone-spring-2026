# Medication Adherence MVP

This is a simple MVP backend prototype for the Butterfly lupus patient medication adherence project.

## Features
- Log medication intake
- Store medication data in SQLite
- Retrieve medication history

## Tech Stack
- Flask
- SQLite

## Files
- app.py (Flask backend)
- requirements.txt (dependencies)
- medication.db (database)

## How to Run

1. Install dependencies:
python3 -m pip install -r requirements.txt

2. Run the app:
python3 app.py

3. Open in browser:
http://127.0.0.1:5000/

## Notes
This MVP demonstrates backend functionality for storing and retrieving medication data.
